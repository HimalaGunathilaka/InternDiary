# Illumination in Computer vision

- **Dark field illumination** ---> Optical technique that enhances constrast in transparent or low-constract specimens by illuminating them obliquely (non directly), causing only scattered light to enter the objective lens.
### Bar lights
![[Pasted image 20260318133453.png]]
- Object is illuminated from different sides.
- Can be used to illuminate specific parts of a object.
- Can be used combination with dark field illumination which makes it easy to inspect for scratches and abnormalities.

### Ring light
![[Pasted image 20260318134019.png]]
- Illuminate the object evenly without casting a shadow.

### Back light
![[Pasted image 20260318134143.png]]
- Object is evenly illuminated from behind so that the outlines are well defined or object is screened.
- **Holes, bubbles or scratches** can be noticed and displayed very clearly.
- However all information regarding the surface texture is lost.

## [CRI](https://www.flexfireleds.com/color-rendering-index-cri-and-led-lighting-what-is-cri/) ( Color rendering index )
- ==Measurement of how natural colors render under an artificial white light source when compared to sunlight.==
	- `100` --> Same as sunlight
	- `90` ---> Great
	- `80` ---> Poor
![[Pasted image 20260318143516.png]]

## [Color temperature](www.studiobinder.com/blog/what-is-color-temperature-definition/)
![[Pasted image 20260318144806.png]]

- ==**Color temperature** is a system that uses numerical values to measure the color characteristics of a light source on a spectrum ranging from warm colors to cool colors.== The numerical value is referred as degrees Kelvin (K).
- Higher values are cooler tones as blue (blue sky measures at 12000 K) and lower values are warmer tones as yellow. (A candle is measures at 1500 K)
- **White balance** ---> Setting in digital cameras that determines which Kelvin temperature will appear as true white. (Natural daylight the temperature would be 5500 K)
