# Range-Base for loop in C++
- Introduced in C++ 11 is a version of for loop that is able to iterate over a range.
- This range can be anything that is iteratable, such as arrays, strings and STL containers.
```cpp
#include <bits/stdc++.h>
using namespace std;

int main(){
	vector<int> v = {1,2,3,4};
	
	for(int i: v){
		cout<<i << " ";
	}
}
```

```
for (declaration: range) {
    // statements
}
```
