# Docker compose
- Compose.yml
```yaml
services:
	mosquitto:
		image: eclipse-mosquitto
		container_name: mosquitto
		volumes:
		- ./config:/mosquitto/config
		- ./data:/mosquitto/data
		- ./log:/mosquitto/log
		ports:
		- 1883:1883
		- 9001:9001
		stdin_open: true
		tty: true
```
- It needs the mosquitto.conf
```bash
listener 1883
listener 9001

protocol websockets
persistence true
persistence_file mosquitto.db
persistence_location /mosquitto/data/

allow_anonymous false
password_file /mosquitto/config/pwfile
```
- Here the mosquitto.conf is configured to use user password based system. The one I shared doesn't follow it.

Guru Meditation Error: Core  1 panic'ed (LoadProhibited). Exception was unhandled.

- **LoadProhibited** = code tried to access an invalid pointer (usually `NULL` or uninitialized object)
- In your case, the culprit is **`wm.server->on("/device-info", ...)`** being called when `wm.server` is **NULL**.
