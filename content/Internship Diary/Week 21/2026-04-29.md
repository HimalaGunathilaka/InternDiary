# Technology being used
- LiDAR 
	- Tracking patients under varying lighting conditions.
- Human detection through vision using ai,
	- Yolo
	- Ex: https://www.nobi.life/en_GB/product, https://vayyar.com/
- [Neuromorphic cameras](https://youtu.be/7xrs9h1SAPo?si=a-_fwv9KpkhqiBY5) or Event based cameras ----> (Only records changes in light intensities)
	- Employed to measure vital signs such as respiration rate and heart rate by capturing subtle chest movements and micro-vibrations induced by blood circulation.
	- Ex: https://www.synsense.ai/products/speck-2/
- [WiFi sensing](https://youtu.be/0OdR8rRMz3I?si=0PmBc3k5kPpF4ky4) (Device free motion) 
	- `WiFi motion` can use the already existing wifi network to use it as a motion sensor.
	- Network disturbances occur when a person walk in between the router and a user. 
	- Can be used to get the pose of the body.
	- This can be use as a bio metric to identify a person as well.
	- Ex: https://www.linksys.com/
- [Smart flooring and pressure carpets](https://youtu.be/XKxyVhrwpCI?si=rT3WhdgURSU6WexQ)
	- Pressure sensitive films placed under existing carpets can track the excat "footfall" pattern.
	- These can distinguish between a human walking and pet running or a object being dropped.
	- Ex: https://www.zibrio.com/shop, https://www.tekscan.com/versatile-pressure-sensing-mats
