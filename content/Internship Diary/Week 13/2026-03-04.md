# Reflection on the day
This part of the report is for reflecting the experience I had today. After finally creating the model for successfully detect number-plates in videos, my next objective was to test it against other models to verify its performance. 
I faced a confusion. Do I find models in Sri Lankan context which detect number plates for this bench marking process or use any model. After short thinking I concluded if the model is already created and published on the internet it should be a good enough model. Since it is already trained to identify vehicle numberplates, it won't be that different in Sri Lanka. But I have to consider about the different standards used in different countries. Also my previous attempt of using static numberplate dataset to train the model didn't work to identify video numberplates at all. Those models might be like that as well. Or may be I had done the same mistake again there to use the old model again. The other thing that I worry is that what if my model is overfitting my current dataset. Currently I ran only for the same domain of dataset. I should change camera and places soon I am not sure whether the youtube video is enough.
My next problem was roboflow my subscription was over. I tried to at least open up my projects. I don't know why I couldn't get pass the pay wall. May be because it was made as a private repo. But surely roboflow should provide a way to turn it to public to use the project again right? I was not concern with following roboflow. So I searched a free local annotation tool to create a new data set from videos. I already found one through youtube. Now I need to select good frames and annotate them. But still I have not got the annotated data from that software and tested out it.
Before going to test the models I concluded it is a good idea first to see how models are evaluated. I saw the same old `accuracy, recall, precision, etc` but this time I finally got what `recall` meaning.
