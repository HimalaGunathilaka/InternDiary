# Evaluation criterias
- ==**Confusion matrix** ==- `N x N` matrix where N is the number of target classes. Represents number of actual outputs and predicted outputs.
	![[Pasted image 20260304162557.png]]

	![[Pasted image 20260304162640.png]]

- ==**Accuracy**== - Ratio of the number of correct predictions to the number of predictions.$$\text{Accuracy} = \frac{TP + TN}{TP+TN+FP+FN}$$
	- Accuracy has a drawback. It cannot perform well on an imbalanced dataset. It can perform on one class better than others.
- ==**Precision**== -----> Measures the proportion of correct positive predictions out of all the predicted values. $$\text{Precision} = \frac{TP}{TP+FP}$$
- ==**Recall**== ----> Out of all the actual positive cases, how many did the model correctly find. $$\text{Recall} = \frac{TP}{TP+FN}$$
	- **TP (True Positives)** = correctly predicted positives
	- **FN (False Negatives)** = positives the model missed

- ==**F1 score**== ----> Is the harmonic mean of precision and recall. It balances both metrics.$$\text{F1 score} = 2 \times \frac{\text{Precision} \times \text{Recall}}{\text{Precision}+\text{Recall}}$$
- ==**AUC-ROC curve**== -----> Commonly used for evaluating the performance of binary classification models. ROC Curve plots the **True Positive Rate (TPR)** versus the **False Positive Rate (FPR)** for different thresholds.
